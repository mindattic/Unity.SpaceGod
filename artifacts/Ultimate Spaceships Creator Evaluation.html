Ultimate Spaceships Creator Evaluation
Asset evaluation · UnitySolarSystem

Ultimate Spaceships Creator

A modular sci-fi ship pack by Ebal Studios on the Unity Asset Store. This page sets out what it is, how it fits the game's ship pipeline, and what adopting it would take.

Promising, but not a drop-in.

It could replace most of the game's procedural and Kenney hulls with one consistent art set, and its colour masks suit faction livery. Two things come first: the repository is public, so the licence decides how the pack can live in the project, and the hand-painted style should be judged against the game's realistic direction in a scratch project before any money or integration work goes in. Of the other packs compared below, MSGDI's capital ships fit the realism direction better, and a ported hull generator is the free option that keeps the repo public.

What the pack is

600example ships, each as a joined mesh and as a modular prefab
219unique modules across 18 design sets
4Khand-painted albedo, metallic, normal and emission maps
10colour variations per ship, through a colour-mask shader
$125single-entity licence, standard Asset Store EULA
462.1 MBdownload size
URPBuilt-in, URP and HDRP supported; the game runs URP 17.4
v7.1released 15 Oct 2026; still maintained

Files are FBX meshes, prefabs (Examples, Modular Examples, Modules), Shader Graph "Colorize" materials and PNG textures. Ships are assembled by hand in the Editor. There are no LODs, and the docs describe no runtime builder.

Pros and cons

For What it gives the game

  • Breadth. 600 hulls in 18 styles, capital ships among them, enough to give every faction and class a distinct look.
  • Faction colours come almost free. The Colorize shader recolours from masks over one texture set. That maps directly onto the per-faction livery ShipModels.MaterialsFor applies today.
  • Warships can still break in two. Modular examples are separate module prefabs, so a hull can be combined into a stern half and a bow half, as wrecks need.
  • One art style. Today the game mixes Kenney low-poly craft with procedural warships. One pack would make the fleet look like it belongs together.
  • URP-ready and maintained. It supports the game's render pipeline, and the latest update is from this month.
  • Cheap to draw. The author reports Colorize costs about the same as a standard material, and a shared texture set per style keeps memory down.

Against What it costs

  • Licence versus a public repo. The EULA allows the assets inside a built game but not redistribution of the source files. They can't be committed to the public GitHub repo.
  • Style may not fit. It is hand-painted and tagged "lowpoly". The game is heading toward realism. Screenshots alone won't settle this.
  • Lighting and shader mismatch. Ships are lit by the game's own Sun-lit Ship.shader. The pack's Shader Graph materials expect URP's normal lights, so one side has to be adapted.
  • No class metadata. Nothing marks an example as a freighter, miner or carrier. Each one has to be picked by eye and mapped to a ShipClass.
  • No hardpoint data. Turrets and damage scars are placed from each class's combat layout, so they won't line up with a new hull until offsets are set per model.
  • Heavy. 462 MB of 4K textures for ships that usually draw as icons a few pixels across. Most of it would be trimmed or downscaled.
  • Built for Unity 2022.3. The listing's original version is 2022.3; the game is on Unity 6 (6000.4). Recent docs reference Unity 6.3 features, so it is probably fine, but this is unconfirmed.

Decide first: where the pack lives

The repository mindattic/UnitySolarSystem is public. The Kenney craft in Resources/Ships are CC0, which is why that was never an issue. This pack needs one of these:

Make the repo privateSimplest. Everything stays in git and fresh clones build as they do today.
Keep the pack out of gitGitignore it and import it locally. The repo stays public, but a fresh clone needs the pack before it shows those ships, so the procedural and Kenney fallbacks must stay.
Private asset repoPut the curated, processed ships in a private repo or submodule. Public code, private art. More moving parts.

What would have to be done

  1. Settle the licence question

    Pick one of the three options above before anything from the pack touches the repository.

  2. Evaluate in a scratch project

    Import into an empty Unity 6 URP project, not this one, so 462 MB never lands in the main repo. Light a few hulls the way the game does (one sun, dark space) and judge the style against the game's realism direction.

  3. Curate two or three hulls per class

    About 20 to 30 ships. Fill the gaps (freighter, miner, breacher) by kitbashing modules or by keeping today's models for those classes.

  4. Prepare the meshes

    Use the joined "Examples" for one-piece ships. For warships, combine the modular example's modules into a stern half and a bow half with the pack's Mesh Combiner, so ShipModels.Build can keep returning two sections and wrecks still break in two.

  5. Normalise like the Kenney craft

    Run each hull through AssetForge's mesh pipeline: one unit long on Z, centred, nose on +Z. Output goes to Resources/Ships, and KenneyModelFor becomes a per-class model table.

  6. Make materials and livery work

    Either teach Ship.shader to sample the pack's albedo, normal and colour-mask textures and keep the game's Sun lighting, or adapt the Colorize Shader Graph to that lighting. Either way, the faction colour drives the mask colour.

  7. Seat the hardpoints

    Turrets, launchers and damage scars are placed from each class's combat layout. Check they sit on the new hull surfaces and add per-model offsets where they float or sink.

  8. Trim the weight

    Copy over only the curated hulls and their texture sets, leave out the Legacy folder, and downscale the 4K maps. Ships under 5 px already draw as icons, so 1K is likely enough.

  9. Verify in the game

    Model viewer (F9), the ship gallery capture, a warship wreck breaking in two, faction colours on every class, and frame time with full system traffic.

The best alternatives found, in two groups: paid packs under the standard Asset Store EULA, which carry the same licence problem as this one, and open sources that can be committed to the public repo as they are. Pick Two realistic routes

  • Keep the repo public: port SpaceshipGenerator's approach into ShipMeshFactory so every warship and freighter gets its own hull, use NASA models (logos removed) for stations, and keep Kenney craft for small civilians. This costs nothing, and nothing has to be moved out of the repo.
  • Buy art, repo private or pack kept out of git: MSGDI's capital collection plus its freighter and miner fits the realism direction better than Ultimate Spaceships Creator and covers the classes this pack lacks, for $110 in total. Ultimate Spaceships Creator remains the choice if a hand-painted style is acceptable.

Ruled out: Jackson's Modular Space Ships (no licence stated, built for Unreal), BuzPin Low-Poly Spaceships (CC BY-ND forbids modified versions), ESA imagery (non-commercial only), and a "16 URP prefabs" pack whose listing says it was made with AI. No free hard-sci-fi capital-ship set turned up.

Still unconfirmed

  • Poly counts: the pack doesn't publish them.
  • What the 77 reviews say: the review text couldn't be read from the store page.
  • Whether any examples read as freighters or miners, the two civilian classes the game shows most.
  • How the hand-painted look holds up under the game's single hard sun light.
